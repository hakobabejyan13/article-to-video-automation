## Content rules

| Date | Decision | Reason | Decided by |
|---|---|---|---|
| 2026-11-07 | The LLM cites sentences by number; code copies the sentence text | A model cannot misquote a sentence it never retypes; weaker or free models become usable | Claude, approved by Hakob |
| 2026-11-07 | `publisher` and `promotional` are set by a person in the article's front matter; the run stops if they are missing | The attribution rule is too important to rest on the LLM | Hakob |
| 2026-11-07 | Self-ranking articles: disclosure card first, an attribution phrase in every publisher claim, and a fixed "Source: {publisher}" tag on screen (was "Source: {publisher}'s guide"; changed in T9, Hakob 2026-11-07) | CLAUDE.md content rule; the tag covers viewers who watch muted | Hakob |
| 2026-11-07 | Fact sheet has one row per claim (each voiceover line, each on-screen fact, each chart value or price) | Every visible number must be traceable to its own sentence | Hakob |
| 2026-11-07 | Checker adds label-value pairing and treats ordinals separately from counts | Stops a value being shown next to the wrong label, and "ranked first" being supported by any "1" | Hakob |
| 2026-11-07 | Checked text and spoken text are stored separately; the lexicon only changes the spoken text | The fact check must run on what is shown, while the voice needs "1,500 pounds" for "GBP 1,500" | Hakob |
| 2026-11-07 | Spoken text is stored for every line (`voiceover[].spoken`), also where it equals `text`; docs show "Spoken as" only where they differ | One rule for later stages: the voice always reads `spoken` | Claude (T4) |
